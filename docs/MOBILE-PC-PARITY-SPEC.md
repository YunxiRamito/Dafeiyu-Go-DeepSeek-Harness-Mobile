# 移动端与 PC 功能对齐需求定稿

确认日期：2026-10-12，Asia/Shanghai。用户已授权实施本稿。以已交付 Android 0.1.24 / code25 为起点，按界面与推理、DSH 与互联、后端与数据三个阶段交付。本文是唯一持续维护的需求基线；进度与证据统一记录到 HANDOVER.md，不能把实现、编译、离线检查、设备验证和用户验收混为一谈。

## 1. 目标、交付顺序与已确认边界

- 安卓公开仓库：YunxiRamito/Dafeiyu-Go-DeepSeek-Harness-Mobile，项目代码 MIT；第三方代码、二进制及素材保留原许可证和来源。
- 正式包名 com.dafeiyu.mobile，使用固定发行签名和正式更新信任，独立安装。不开发预览版迁移功能；用户已确认预览版没有对外发布。
- 后续版本从 0.1.25 / code26 递增。
- 包含必要的 PC、Connect、Aries、DeveloperCenter 改动、后端部署、公网联调。既有仓库在当前分支提交推送，保留别人未提交改动。
- Connect 插件源码新建独立公开仓库发布；DeveloperCenter 后端不新建源码仓库（2026-10-13 用户确认）。
- 手机、电脑使用同一份冻结 Connect 包，版本、字节和 SHA-256 一致。

| 引擎 | 本地 | 在线 |
| --- | --- | --- |
| 官方轻引擎 | 原生界面，由手机调用模型和执行本机工具 | 原生界面，任务交给电脑 DSH，实时接收状态 |
| DSH | 启动手机 DSH，应用内打开本机网页 | 应用内打开电脑 DSH，全部请求经 Aries 加密中继 |

在线工作区以电脑为实际存储与执行端。手机同步目录信息、会话、模型目录、公开思考、工具、子 Agent 和任务状态；文件夹选择浏览对应电脑的目录。产物留电脑，用户手动点击才下载。先前按同名工作区建立双向文件副本的设想已经被此确认取代。

## 2. 阶段一：界面、推理与设置修复

- 玻璃：沿用 Apple Liquid Glass，出现、过渡、消失统一动画。圆按钮阴影淡且范围小；二级关闭按钮透明，无圆底、无阴影。暗色主题按钮提高亮度、白字。粘连仅在按下且距离近或运动且距离近时出现，静止消失。归档黄、删除红，输入区和状态条保留半透明可读材质。
- 工作区：非空也开放删除，两次独立左滑，第一下展开动作，第二下触发。移除记录时归档其对话；磁盘文件另外询问，默认保留，显示执行设备及真实路径。活跃任务先选择停止或取消，等待真实停止。
- 推理：DeepSeek 从模型 API 的 effort.supported_levels/default_level 和关闭能力生成档位，缓存能力并发送正确 thinking/reasoning_effort。DSH 用真实目录的 reasoning.efforts/defaultEffort。切换模型校验原选择，不硬编码所有模型相同的档位。
- 官方轻引擎：删本地响应模式，以推理控制；加默认关闭的节流模式，实际接入少 token、避免重复探索、简洁回答的任务提示。流式输出、显示思考、默认全部展开全部接线，默认展开关闭。隐藏思考只影响展示，不丢记录。
- DSH：真实状态“正在运行 · 端口 XXXX”/“已停止”，启动、停止、重启接实际进程；启动期间按钮改重启。本地选择 DSH 自动启动并打开本机网页，失败进设置说明原因；在线只连电脑。删更新页重复自动启动。主页自动启动在选 DSH 时动画收起，边框随高度移动；切回官方恢复原值。
- 个性化：减少透明度并入玻璃材质，减少动态效果改省电。启用时关闭并锁定玻璃、页面切换、按钮 Q 弹，关闭后恢复原值。前台在线正常，后台暂停 Aries/SSE 常驻及自动下载；电脑任务继续，回前台补读；厂商/FCM 提醒保留且不触发下载。
- 整理：删混合模式、字体、用量预览、模型页“DSH 引擎/本地轻引擎”占位、支持区重复公告。环境为组件和虚拟机运行详情。线上主页显示 Aries 已连接/未连接及对端简讯，区分服务器与电脑在线。
- 提供商：左长按排序把手，右透明铅笔及更多。仅内置 DeepSeek 官方受保护，行上无编辑/更多，API Key 用专用入口；其他可编辑删除。在线仅切换电脑已有提供商/模型，禁止新增、编辑、排序、删除及改 Key/地址。
- 权限：通知说明与授权入口；扫码申请相机；打开左下加号立即说明并申请媒体权限，支持有限照片授权；所有文件任务需要时申请。拒绝则暂停或改用无权限方式，不强制反复弹窗。

阶段一交付真实 DeepSeek 修复和界面。后续服务未接通的控件禁用并标预留，禁止假按钮。

## 3. 阶段二：执行、共享模型、插件与 Aries

- 环境：完善 Ubuntu/PRoot、Node、Git、pnpm、Python 真安装/修复/检测/版本/进度/取消。运行详情显示环境类型、资源、进程和日志。补来源/摘要校验的 x86_64 资源供 QA 验证，不能用 ARM 翻译冒充原生可用。
- 多提供商：DeepSeek 官方保留原生；其余通过独立按需 Node worker 复用固定 pi-ai。首次引导安装“模型运行组件，含 Node.js 与 Linux 基础环境”。只负责目录、认证及模型请求/流，工具调用返回 Android 调度器，权限/技能/脚本/任务归应用；不启动 DSH Web。
- 协议：覆盖实际 PC 十协议及各自 API Key/OAuth/SigV4/Azure/Vertex 认证。缺组件、ABI、worker、认证错误分开反馈，不静默替换提供商。
- 共享：轻引擎和手机 DSH 同提供商配置及排序，经 PC 真实 settings/credentials 适配。共享兼容历史、支持切换续聊，保留工具来源；受控导入持久历史，不重放旧提示/工具。
- 本机 DSH：固定包/依赖/integrity、候选目录、占用保护、探测后切换、旧版回退。后端真实 Linux 安装及版本元数据。更新遇到任务由用户选择立即中断或稍后。
- 沙箱：PC 相同只读/工作区内修改/完全权限及审批预设，先真实 bubblewrap/Landlock 探测，验证越界写、截断、链接、子进程。若不满足，按用户“真需要的话需要问我”，先交探测、完整内核 VM 候选与资源成本，确认再引入；PRoot 不是安全隔离。
- Connect：Android 真启动宿主和本地桥，保留 dafeiyu-go.connection.v1；新能力计划冻结 0.3.0 双端相同包。0.2.0 只保留旧能力，新增任务/目录/设置/网页能力门控。
- 原生在线：真实 workspace/目录/session/activity，正文、公开思考、工具、子 Agent、进度、目录实时更新；稳定请求 ID，重连不重复任务；本地模型/推理/插件/技能不用于电脑执行。
- 远程设置：切换已配置提供商、模型、推理、沙箱，写电脑全局默认影响后续会话。真实持久化完成才成功；原生和网页统一 PC 桥权限约束。
- 网页：Android 仅 loopback HTTP+WS 代理，资源/RPC/remote.mux 全经统一加密隧道与 Aries。PC 私存上游认证，重写 Host/Origin，维持手机同源；分流/顺序/缓冲/背压/取消/超时/重连，必要补等待消息。
- 配对：按 capability 接 device_name 和 Aries 0.0.4 确认/取消/生命周期；关系与 presence 独立，离线不清配对，不猜型号；精确匹配持久终态才清组凭据，保留设备身份/pin。
- 扩展：插件拼图、技能灯泡分页面；插件再分 Dafeiyu/DSH 子页，PC 在线本地搜索/详情/安装/启停/更新/删除/修复齐全。技能真接轻引擎发现/读取/应用。手机独立 GitHub 推荐清单。
- 下载：默认国内 CDN，沿 PC 源逻辑；(1,6] MiB 四线程，>6 MiB 八线程，覆盖组件、APK、技能插件、npm tarball、手动产物。统一下载层，Range 不可用先换源，再无则单流并说明。SHA/ETag/续传/取消/换源校验齐全。
