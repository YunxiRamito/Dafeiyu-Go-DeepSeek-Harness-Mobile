## 分工与边界

主 Agent 负责共享玻璃集成、最终代码审查、串行整包构建、硬件加速模拟器和交付。用户随后指定子 Agent 改为 Sol high：三位 Astra low worker 已交接并关闭，由 6.1 Sol/high 接续工作区、回执、QA 脚本，另由 Sol/high 维护玻璃 focused 检查。滚动 worker 已完成并关闭。每项修正先确认真实问题，保留他人改动。统一最终包后才绑定 APK hash 与设备结果。

重大功能研究沿用 `research/liquid-glass-20261012/REPORT.md` 与 Compose 评审中已实际获取的固定源码及许可。没有新增上游依赖。研究不等于本批设备验收。
