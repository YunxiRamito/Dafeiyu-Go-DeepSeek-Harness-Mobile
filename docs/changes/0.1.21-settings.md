# Settings Page Fixes - Version 0.1.21

Date: 2026-10-12
Status: Code changes applied; build verification pending (pre-existing errors in PairingScreen block full compilation)

## Issues Fixed

### 1. Invalid Material Effect Toggles (P1)
- **液态玻璃材质 (Liquid Glass Material)**: Now disabled and marked "(预留)" (Reserved)
- **页面切换效果 (Page Transition Effect)**: Now disabled and marked "(预留)"
- **按钮 Q 弹效果 (Button Spring Effect)**: Now disabled and marked "(预留)"

Location: `SettingsScreens.kt:758-762`
Rationale: These toggles were non-functional (not wired to actual UI rendering). Disabled to prevent user confusion.

### 2. Invalid Notification Toggles (P1)
- **灵动岛通知 (Live Island Notifications)**: Disabled, marked "(预留)"
- **公告推送 (Announcement Notifications)**: Disabled, marked "(预留)"
- **通知推送 (General Notifications)**: Disabled, marked "(预留)"
- **连接的设备推送 (Device Connection Notifications)**: Disabled, marked "(预留)"

Location: `SettingsScreens.kt:919-925`
Rationale: These toggles were not connected to notification system integration. Disabled until proper implementation.

### 3. DSH Engine Unavailable (P1)
- **DSH 引擎**: Now disabled and marked "(未接入)" (Not Integrated)
- Prevents users from selecting a non-functional engine

Location: `SettingsScreens.kt:116-118`
Rationale: Selecting DSH engine made chat impossible to send. Disabled until backend integration is complete.

### 4. API Key Clearance Confirmation Dialog (P0)
- Clear button now shows confirmation dialog
- Dialog warns: "会中止当前回复和子任务" (Will stop current reply and sub-tasks)
- User must explicitly confirm before clearing

Location: `SettingsScreens.kt:585-599` (modified), `SettingsScreens.kt:2104-2127` (added dialog)
Changes:
- Added `showClearKeyConfirm` state in ModelsContent()
- Added AlertDialog with warning message
- Modified clear button to trigger dialog instead of immediate clear

### 5. Font Settings Page Fixes (P1)
- **Removed nested scroll**: Deleted FishCard wrapping entire vertical scroll
- **Removed duplicate title**: Removed "字体设置" heading + subtitle
- **Removed back button redundancy**: Button now only at top
- **Clean layout**: Content directly in Column with single scroll

Location: `FontSettingsScreen.kt:40-215`
Rationale: Nested scrolling could cause crashes. Simplified layout improves stability and UX.

### 6. Font Family Selection Hidden (P1)
- Removed entire "字体族" (Font Family) section
- System only supports two families; hiding reduces UI clutter
- Size and weight controls remain active

Location: `FontSettingsScreen.kt` (removed lines ~79-108 in original)
Rationale: FishTheme.kt hardcodes SansSerif; selection was non-functional.

## Code Changes Summary

### Files Modified
1. **SettingsScreens.kt**
   - Added `graphicsLayer` import for disabled state styling
   - Updated appearance toggles to disabled with `enabled=false`
   - Updated notification toggles to disabled with `enabled=false`
   - Disabled DSH engine choice row
   - Added API Key clear confirmation dialog state and UI
   - Modified `HomepageChoiceRow()` signature to support `enabled` parameter

2. **FishComponents.kt**
   - Updated `ToggleRow()` composable to accept `enabled: Boolean = true` parameter
   - Added `.graphicsLayer { alpha = if (enabled) 1f else 0.5f }` for visual feedback
   - Updated Switch component to respect enabled state

3. **FontSettingsScreen.kt**
   - Removed nested scroll container
   - Removed title/subtitle section
   - Removed font family selection card
   - Kept size and weight controls
   - Simplified to single-scroll experience
