# Android 立项与前端设计

日期：2026-10-10，Asia/Shanghai。当前交付目标是两模式原生 Android 前端：轻量对话默认打开，DSH 接入模式切入后自动演示启动；后端实现方式留待下一轮讨论。最终覆盖本地运行与电脑连接，优先手机本地；远程复用既有 Dafeiyu-GO-Aries 协议，不重新设计微端。

## 设计方向

借鉴 WP8 的文字主导、大标题和页面内 Pivot：用少量清楚的入口引导任务，避免把桌面设置全部塞在首页。WinUI 3 / Win11 提供表面层次、圆角、细描边与克制的强调色；不仿照桌面标题栏、Windows 控件尺寸或 Mica 系统材质。

页面边距按用途为 16–32dp；标题 28–29sp / SemiBold；主体 14–16sp；辅助说明 10–13sp。实际对齐 PC 实色背景：浅色 `#F3F3F3`、近白卡片、强调蓝 `#0067C0`，深色背景 `#202020` 和卡片 `#2B2B2B`。控件 / 卡片 / 浮层圆角 4 / 6 / 8dp；侧栏使用中性选中底和窄蓝标记。卡片最多一层嵌套，以留白分组。触摸动作约 48dp，图标使用原创单色 Canvas 路径，支持系统字号、滚动及输入法避让。

| 入口 / 模式 | 主要任务 | 次级功能 |
|---|---|---|
| 轻量对话（默认） | 打开即可输入、阅读模拟回复、停止/新建 | 多行输入、附件和模型示意 |
| DSH 接入模式 | 切入后自动演示启动，展示独立工作区与对话状态 | 演示进度、运行状态、停止/重启与日志 |
| 左上菜单 | 选择两种模式、访问会话和设置 | 设置隐藏为次级入口，返回原对话上下文 |
| DSH 左下软件设置按钮 | 跳转原生设置 | 预演未来插件注入，当前没有实际插件 |
| 设置 / 关于 | 调整演示偏好、了解版本和模式 | 数据与下载等既有页面保留在次级层级 |

本轮移除常驻底部四入口，以对话作为主页面，左上菜单管理模式与次级功能。DSH 左下软件设置按钮留在对话区作为插件注入功能示意，不能使用户以为实际服务已经接入。页面淡入约160ms，无闪烁背景、夸张阴影或玻璃叠层。所有界面状态与真实后端分离；只用内存 `DemoRepository` 驱动。

轻量模式无需等待DSH状态即可体验模拟回复。DSH模式的自动启动属于模式进入事件，不应由普通重组、旋转、进入设置后返回或恢复菜单重复触发。模式切换、新建会话与停止生成应有明确规则，避免一条延迟的旧回复写入另一个模式或新会话。此处规定前端状态行为，不启动后台服务。

返回顺序以当前可见上下文为准：先收起输入法或弹层/菜单，再返回上级设置，最后回到原模式对话；对话根页由Android处理退出，不再跳回旧运行页。输入区使用Android窗口/Compose inset避让，保证键盘弹出后发送与停止按钮可达，并避免底部系统导航、IME和容器padding重复累加。具体交互以本轮最终实现及用户试用为准。

## 前后端接缝

目前 `DemoRepository` 表达模式、运行、对话与拓展的演示状态。轻量对话和DSH接入模式都只使用本机模拟回复，不暗示已经选择了真实轻量API或远程DSH方案。后续拆出真实 runtime 与会话能力时，再讨论每种模式的实际数据来源、会话隔离与密钥管理；没有预先绑定 DSHA 容器类或复制其 UI。

本地候选路线是随 APK 交付可追溯的 proot 启动器、私有 Ubuntu/glibc 运行资产、Node 与 DSH；前台服务、运行锁、token/cookie、文件导入导出、升级回切都待真实 PoC。仅内嵌 Node 不能推导原生依赖兼容；proot 不提供同 UID 插件的安全隔离。

Aries 只浅读 README、HANDOFF 和客户端协议：现有 `/api/v1/public` 提供 Ed25519 设备签名、群组、长轮询、密文消息和分块文件；管理 API 与设备 API 分开。这是可复用的协议基础，不等同于完整的远程 DSH 控制或会话 UI。其 README 明确当前是单节点原型，DSH 同步插件和客户端仍需衔接；当前不改 Aries，不接生产服务。

## 版本约定

按用户要求，现阶段修订使用 `0.1.0 → 0.1.1 → 0.1.2`，前端重构仍属于 `0.1.x`。对外显示版本与 Android 内部递增 versionCode 分开管理。本轮版本为 `0.1.1`，不再使用误标的 `0.2.0`。
